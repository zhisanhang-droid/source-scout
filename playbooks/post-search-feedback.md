# Post-search Feedback Playbook

Use this after a search task, especially when the user reacts to answer quality.

## Feedback Fields

- Which sources were high value?
- Which sources were noisy?
- Which access methods failed?
- Which query terms unlocked useful results?
- Which source types were missing?
- Which source card should be updated?

## Feedback Block Template

```markdown
## Source Scout Feedback

Task:
Sources used:
High-value sources:
Low-value or stale sources:
Access failures:
New source candidates:
Query patterns to keep:
Source Map updates proposed:
User feedback:
```

# Chinese Community Keywords

Use these terms when searching Chinese developer communities. Keep them here in Markdown so YAML source cards stay easy to parse.

| Intent | Chinese query terms |
|---|---|
| Web scraping | 爬虫, 数据采集, 抓取 |
| Logged-in session | 登录态, cookie, 浏览器 profile |
| Captcha / anti-bot | 验证码, 风控, 反爬 |
| Browser extension | 浏览器插件, Edge 插件, Chrome 插件 |
| Userscript | 油猴脚本, Tampermonkey |
| Local bridge | 本地代理, 本地服务, localhost |
| Alternative tools | 替代, 平替, 开源 |

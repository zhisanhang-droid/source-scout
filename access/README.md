# Access Surfaces

An access surface is a concrete way to retrieve information from a source.

Examples:

- `reddit_google_site_search`
- `reddit_native_global_search`
- `reddit_comment_deep_read`
- `github_issue_global_search`
- `github_code_search`

This is more specific than a source card. A source card says what a source is good for. An access surface says how to actually get information from it, what depth can be retrieved, how to validate the route, and where to fall back if it fails.
